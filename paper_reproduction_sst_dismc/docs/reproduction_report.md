# 复现实验结果分析报告

## 1. 目标图趋势对齐说明（图7~图11）

> 由于当前仓库未包含论文 PDF 原图，本报告按“趋势一致性”对齐论文图7~图11常见结论。

### 图7（启动响应）
- 本复现：DISMC 启动超调更小，上升更快，调节时间最短。
- 趋势判断：与论文结论一致（DISMC > SISMC > PI）。

### 图8（负载突变）
- 本复现：120Ω→60Ω→120Ω 时，DISMC 电压跌落幅度更小，恢复更快。
- 趋势判断：一致。

### 图9（参数摄动）
- 本复现：L ±15% 下，DISMC 轨迹最接近参考，波动最小。
- 趋势判断：一致。

### 图10（综合扰动）
- 本复现：0.1s 负载变化、0.2s 输入参考变化、0.3s 输出参考变化下，DISMC 跟踪偏差更小，恢复更快。
- 趋势判断：一致。

### 图11（输入侧与级间稳定）
- 本复现：C 相电压电流保持近同相趋势；vdc 在扰动后恢复至新平衡。
- 趋势判断：定性一致。

## 2. 不完全一致项
1. 峰值绝对数值、微小振荡频率与论文可能存在偏差。
2. 三相侧与 DAB 采用平均模型，不是全开关级详细仿真。
3. 论文若采用更高阶非线性项或精确参数，本复现用工程参数替代。

## 3. 误差原因
- 论文完整参数未全部公开（如控制器精确增益、采样同步、死区、滤波器细节）。
- 本工程优先实现“可运行+趋势复现+可二次修改”，因此采用了可调平均模型。
